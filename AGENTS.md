# AGENTS.md

## Project Overview

`act3-runner` runs [act3](https://github.com/dhth/act3) against the repositories in `repos.txt` and publishes the resulting HTML reports to GitHub Pages (https://actions.gh.dhruvs.space) twice a day via `.github/workflows/deploy.yml`.

## Common Commands

Read `mise.toml` for available development tasks and tools.

## Layout

- `main.yml`, `pr.yml`, `release.yml`, `scan.yml`, `vuln.yml` (repository root) are act3 configs, not GitHub workflows. They are generated by `mise run gen`; don't edit them by hand. Regenerate them after changing `repos.txt`.
- `templates/report.html` is the act3 HTML template for the reports.
- `assets/` is copied as is into `dist/`; `assets/index.html` links to every report.

## Gotchas

- Run the `gen:*` tasks one at a time (`mise run gen` does). Running them in parallel hits GitHub's secondary rate limit, and a failed task leaves its config truncated.
- Adding a report type takes a `gen:*` and a `run:*` task, an entry in the `report` task's loop, and a link in `assets/index.html`.

## Workflows

- Workflows must pass jactionlint's `default` profile (`mise run lint:actions`).
- Pin actions to full commit SHAs with `jactionlint --online --fix`, not by hand.
- The deploy job keeps `cache: false` on mise-action and grants permissions at the job level only.
